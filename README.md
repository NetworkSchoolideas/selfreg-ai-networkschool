# SelfReg AI Landing

Публичный лендинг проекта SelfReg AI для презентации психологической модели саморегуляции подростков, исследовательской основы и педагогического сценария поддержки.

## Что внутри

- `index.html` - статическая страница лендинга.
- `styles.css` - дизайн-система, адаптивная верстка, светлая и темная темы.
- `i18n.js` - переключение RU/EN и текстовые версии интерфейса.
- `assets/` - фоновые изображения, схемы, видео и аудио проекта.
- `vercel.json` - минимальная конфигурация статического деплоя на Vercel.

## Публичная логика

Лендинг ведет в одну публичную точку входа приложения. Разделение ролей, доступов и внутренних экранов остается внутри приложения, а не раскрывается отдельными публичными ссылками с сайта.

## Перед публикацией

1. Проверить RU и EN версии.
2. Проверить светлую и темную темы.
3. Проверить desktop, tablet и mobile.
4. Убедиться, что видео и аудио воспроизводятся из `assets/media/`.
5. Проверить, что в публичном тексте нет внутренних технических описаний.
