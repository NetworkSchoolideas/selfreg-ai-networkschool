# SelfReg AI Landing

Публичный статический лендинг проекта SelfReg AI: продуктовая презентация психологической модели саморегуляции подростков, исследовательской основы и педагогического сценария поддержки.

## Локальный запуск

Проект не требует установки зависимостей и отдельной сборки. Из корня репозитория:

```powershell
py -3 -m http.server 4317 --bind 127.0.0.1
```

После запуска лендинг доступен по адресу `http://127.0.0.1:4317/?lang=ru`.

## Структура

- `index.html` — основная страница лендинга.
- `styles.css` — дизайн-система, темы и адаптивная верстка.
- `i18n.js` — RU/EN-переключение и локализованный текст.
- `privacy.html`, `terms.html` — локальные страницы закрытого тестирования.
- `assets/` — изображения, схемы, видео и аудио проекта.
- `vercel.json` — конфигурация статического деплоя.

## Публикация

Vercel публикует корень репозитория как статический сайт: Framework Preset — `Other`, Build Command отсутствует, Output Directory — `.`. Каждый push в подключенную ветку запускает новый деплой.
