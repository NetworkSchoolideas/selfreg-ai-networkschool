# SelfReg AI Landing

Публичный статический лендинг проекта SelfReg AI: продуктовая презентация психологической модели саморегуляции подростков, исследовательской основы и педагогического сценария поддержки.

## Локальный запуск

Проект не требует установки локальных зависимостей и отдельной сборки. Для
production-подобной поддержки чистых URL (`/privacy`, `/terms`) из корня
репозитория:

```powershell
npx.cmd --yes serve . -l 4317
```

После запуска лендинг доступен по адресу `http://127.0.0.1:4317/?lang=ru`.
`npx` может загрузить или использовать кэш утилиты `serve` вне репозитория.

Стандартный `python -m http.server` подходит для просмотра отдельных файлов,
но не воспроизводит clean URLs Vercel и возвращает 404 для ссылок на страницы
закрытого теста.

## Быстрая проверка маршрутов

После запуска локального сервера:

```powershell
node scripts/landing-smoke.mjs
```

Скрипт проверяет RU/EN главную страницу, clean URLs правил и
конфиденциальности, а также доступность основного CSS. Можно передать другой
адрес, например production: `node scripts/landing-smoke.mjs https://example.com`.

## Структура

- `index.html` — основная страница лендинга.
- `styles.css` — дизайн-система, темы и адаптивная верстка.
- `i18n.js` — RU/EN-переключение и локализованный текст.
- `privacy.html`, `terms.html` — локальные страницы закрытого тестирования.
- `assets/` — изображения, схемы, видео и аудио проекта.
- `vercel.json` — конфигурация статического деплоя.

## Публикация

Vercel публикует корень репозитория как статический сайт: Framework Preset — `Other`, Build Command отсутствует, Output Directory — `.`. Каждый push в подключенную ветку запускает новый деплой.
