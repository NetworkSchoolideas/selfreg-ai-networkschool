# SelfReg AI Landing: Deploy Notes

Эта папка содержит статическую версию лендинга, готовую к публикации через GitHub и Vercel.

## Состав

- `index.html` - основная страница.
- `styles.css` - визуальная система и адаптивная верстка.
- `i18n.js` - RU/EN переключение и локализованный текст.
- `assets/` - изображения, схемы, видео и аудио.
- `site.webmanifest` - базовые метаданные сайта.
- `vercel.json` - настройки статического деплоя.

## Деплой на Vercel

1. Запушить репозиторий на GitHub.
2. В Vercel выбрать `Add New Project`.
3. Импортировать репозиторий.
4. Framework preset: `Other`.
5. Build command: оставить пустым.
6. Output directory: `.` или пустое значение.
7. Deploy.

## Проверка перед push

- Открывается главная страница.
- Работают якоря навигации.
- Работает переключение RU/EN.
- Работает переключение светлой и темной темы.
- Видео и аудио загружаются из локальных файлов репозитория.
- В публичном лендинге нет внутренних технических описаний, тестовых маршрутов или демонстрационной логики.

## Медиа

Видео и аудио лежат в `assets/media/` и будут загружаться вместе с репозиторием. Каждый файл меньше лимита GitHub в 100 МБ, но общий вес медиа заметный, поэтому перед финальной публикацией стоит отдельно проверить скорость загрузки на Vercel.
