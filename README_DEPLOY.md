# SelfReg AI landing: deployment package

Эта папка - чистая версия лендинга для публикации на GitHub и Vercel.

## Что внутри

- `index.html` - двуязычный лендинг проекта.
- `styles.css` - визуальная система и адаптивная верстка.
- `i18n.js` - переключение RU/EN и тексты интерфейса.
- `assets/` - схемы, фоны и визуальные материалы.
- `vercel.json` - минимальная конфигурация статического деплоя.

## Позиционирование проекта

Лендинг сделан как конкурсная витрина: проблема настоящего, психологическая модель, доказательная база, текущая апробация логики и образ будущей системы.

Целевая техническая реализация - веб-приложение на Vercel: экран подростка, дашборд педагога, API-слой, база данных и подключаемый AI-провайдер. Текущий диалоговый сценарий используется как проверка логики модели и переносится в веб-интерфейс.

## Быстрый деплой через Vercel

1. Создать GitHub-репозиторий, например `selfreg-ai`.
2. Загрузить содержимое этой папки в корень репозитория.
3. В Vercel выбрать `Add New Project` и импортировать репозиторий.
4. Framework preset: `Other` или статический проект.
5. Build command: пусто.
6. Output directory: пусто или `.`.
7. Deploy.

## Следующий технический шаг

После публикации статического лендинга переносим прототип в веб-приложение:

- `app/student` - диалог подростка;
- `app/teacher` - дашборд педагога;
- `app/api/chat` - вызов LLM через API;
- `app/api/dashboard` - данные для педагога;
- `lib/model` - психологическая логика этапов и сценариев A/B;
- `lib/providers` - Sber GigaChat, OpenRouter и другие совместимые API;
- база данных - сначала простая, затем Vercel-compatible storage.
